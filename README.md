## SupplyLens

SupplyLens is a family of Python tools that share one idea: a prediction is only useful if it comes with a reason and a recommended action. Each project has a command line, an interactive dashboard, a test suite and sample data you can run in a few minutes.

| Project | What it answers |
|---|---|
| [supplylens](https://github.com/MDABDURRAUF/supplylens) | Which purchase orders will arrive late, why, and what to do about it |
| [supplylens-control-tower](https://github.com/MDABDURRAUF/supplylens-control-tower) | Which open orders need a decision today, and did past decisions work |
| [supplylens-sme-sourcing](https://github.com/MDABDURRAUF/supplylens-sme-sourcing) | Where a small business should buy, counting duty, freight and cash limits |
| [supplylens-network-simulator](https://github.com/MDABDURRAUF/supplylens-network-simulator) | How a service or goods network holds up under a disruption |
| [supplylens-shipment-risk](https://github.com/MDABDURRAUF/supplylens-shipment-risk) | Which shipments will be late and what delivery date can be promised |
| [supplylens-early-warning](https://github.com/MDABDURRAUF/supplylens-early-warning) | Which signals point to trouble before it reaches orders |
| [supplylens-distribution-optimizer](https://github.com/MDABDURRAUF/supplylens-distribution-optimizer) | How to serve demand from warehouses at the lowest cost |
| [supplylens-supplier-risk](https://github.com/MDABDURRAUF/supplylens-supplier-risk) | Which suppliers are getting riskier, and on what evidence |
| [supplylens-replenishment](https://github.com/MDABDURRAUF/supplylens-replenishment) | What to reorder, how much and when |
| [supplylens-compliance-monitor](https://github.com/MDABDURRAUF/supplylens-compliance-monitor) | Which records break a compliance rule and need follow-up |

The sample data in every project is simulated and labelled as such. Results on it show that a method works; they are not findings about real companies.

## Get involved

Questions, ideas and corrections are welcome, whether you write code or not.

- **Ask or suggest:** open a thread in [Discussions](https://github.com/MDABDURRAUF/supplylens/discussions).
- **Start small:** look for issues labelled [good first issue](https://github.com/MDABDURRAUF/supplylens/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22).
- **Report a problem:** open an issue in the project it concerns. A small example that reproduces it helps most.
- **Work in supply chain?** Feedback on whether the outputs match how planners actually decide is as valuable as code.

How to contribute is described in the [contributing guide](https://github.com/MDABDURRAUF/.github/blob/main/CONTRIBUTING.md).
